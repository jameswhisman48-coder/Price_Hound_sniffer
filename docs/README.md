- `research-verification.md` — verification notes supporting the current data strategy.
- `research-target-api.md` — Target API/browser research and production-readiness limitations.

- `beta-invite.md` — friends-and-family Cincinnati pilot invitation and test guidance.
- `instagram-campaign.md` — draft Instagram campaign content.
